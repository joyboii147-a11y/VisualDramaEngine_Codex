# 05 — ตรวจรับก่อนส่ง (`reviewer`)

Reviewer **อ่านอย่างเดียว ไม่แก้ไฟล์** ตรวจ Scene ที่ได้รับเทียบกับแหล่งหลัก แล้วส่งผลกลับให้ agent หลัก ตรวจจากเอกสารเท่านั้น ห้ามเขียนว่าภาพ ใบหน้า หรือคลิป "ผ่าน" เพราะยังไม่มีผลผลิตจริง

อ่าน: `EPxx/shots/SCxx.md`, ไฟล์ prompt ของ Scene นั้นทั้งหมด, `EPxx/01_breakdown.md`, `EPxx/02_emotion_map.md`, `EPxx/03_setup_map.md`, `bible/`, และ `state/story_state_ล่าสุด.md` ถ้ามี

## 1. บทและเรื่อง

1. ทุก Dialogue ID ของ Scene ถูกใช้ตามลำดับ ไม่หาย ไม่ซ้ำ ไม่เพิ่มคำ นำส่วนที่แบ่งมาต่อกันแล้วได้บทต้นฉบับตรงตัว
2. บทพูดใน Shot และใน video prompt ตรงกับ Dialogue Ledger ทุกตัวอักษร
3. ไม่มีตัวละครสำคัญ เหตุการณ์ หรือสถานที่ที่บทไม่มี
4. Reaction เกิดหลังตัวละครรับรู้ข้อมูล ไม่มีใครแสดงว่ารู้สิ่งที่ตาราง "ใครรู้อะไร" ในใบสถานะบอกว่ายังไม่รู้
5. ช่วงไม่มีบทพูด (มอนทาจ อินเสิร์ต แอ็กชัน) ใน breakdown ถูกแตกเป็น Shot ครบ
6. ทุก Shot มีหน้าที่ชัด ผ่านคำถามตรวจ 3 ข้อใน engine/02 หัวข้อ 3

## 2. ตัวละครและชุด

7. รหัสชุดในช่องตัวละครที่เห็นของทุก Shot ตรงกับตารางชุดของตอนใน `03_setup_map.md` ตาม Beat ภาพที่แนบเป็นภาพของชุดนั้น และชุดใน prompt คัดลอกคำบรรยาย LOCKED จาก Bible ตรงตัว
8. การเปลี่ยนชุดมีการเปลี่ยนเวลาหรือการกระทำรองรับ
9. สภาพร่างกายที่ค้างอยู่ (แผล ผมเปียก รอยน้ำตา) ต่อเนื่อง
10. CAST COUNT ตรงจำนวนคนที่เห็นจริง รวมคนหน้าเฟรม ช็อตเดี่ยวมีหนึ่งคน
11. OTS: เจ้าของไหล่มีชื่อและลักษณะครบ แยกด้านไหล่กับขอบเฟรม เสื้อชั้นนอกและผมตรง Bible
12. ภาพที่แนบเลือกถูกตามตารางใน engine/03 หัวข้อ 3 (ภาพชุดตรงกับ Wardrobe State, face.png สำหรับ MCU หรือแคบกว่า) path ไฟล์มีอยู่จริงใน input/characters/ บล็อก REFERENCE IMAGES ลำดับและหน้าที่ภาพตรงกับช่อง "แนบใน OpenArt" ข้อความไม่บรรยายหน้าแข่งกับภาพ และไม่ขัดกับภาพชุด จำนวนภาพแนบไม่เกินกฎข้อ 9 ใน AGENTS.md
13. แนบรูปเฉพาะคนที่เห็นในภาพนั้น

## 3. ผัง กล้อง แสง พร็อพ

14. ทุก image prompt มี SCENE GEOGRAPHY, CAMERA POSITION, VIEW DIRECTION, VISIBLE BACKGROUND, OFF-FRAME ที่ไม่ขัดกัน และตรงกับ `03_setup_map.md`
15. ไล่เส้นมอง กล้อง → ตัวละคร → ผนังด้านหลัง แล้วพื้นหลังที่เขียนถูกต้อง ไม่คัดลอกจากมุมอื่น
16. แกนสนทนา ทิศสายตา ตำแหน่งซ้าย-ขวาคงที่ทั้งฉาก แหล่งแสงไม่ย้ายฝั่ง
17. พร็อพ: ผู้ถือ มือ ตำแหน่ง สถานะ ต่อกับ Shot ข้างเคียง ไม่ reset ไม่ย้ายเอง

## 4. Prompt

18. ทุกไฟล์ prompt อ่านแยกเดี่ยวได้ ไม่มีคำต้องห้ามใน engine/03 หัวข้อ 1 ไม่มี placeholder หรือวงเล็บค้าง
19. Image และ video prompt ของคลิปเดียวกันบรรยายพื้นที่ ชุด ตำแหน่ง แสง พร็อพ ตรงกัน และ Start State ของ video ตรงกับ START STATE ของ image
20. คลิปที่ต่อจากเฟรมสุดท้าย: Start State ตรงกับ End State ที่วางแผนไว้ของคลิปก่อน และไม่มีไฟล์ image
21. สีหน้าเริ่มของแต่ละคลิปต่อจากสีหน้าจบของ Shot ก่อน เว้นแต่มีการข้ามเวลา
22. เสียง: โหมดเดียวต่อคลิป ON/OS/VO ถูกต้อง Voice Identity ตรงกับ Bible ทุกตัวอักษร B-roll ไม่มีคำสั่งพูดบท A-roll คนที่เห็นแต่ไม่พูดอยู่ในช่อง NON-SPEAKERS
23. ทุกไฟล์ .txt มีส่วนหมายเหตุตาม engine/07 หัวข้อ 4: รายชื่อตัวละครในเฟรมครบทุกคนที่เห็นส่วนใดส่วนหนึ่ง (รวมหันหลัง มือ เงาสะท้อน คนเบลอ) จำนวนตรงกับ CAST COUNT รหัสชุดตรงกับไฟล์ Shot มีหัวข้อคนที่เกี่ยวข้องนอกเฟรม เส้นคั่นถูกต้อง และใต้เส้นคั่นไม่มีบรรทัด `#` หรือภาษาไทยนอกบทพูด
24. Insert ที่มีข้อความในภาพ ระบุข้อความตรงตัวและห้ามข้อความอื่น

## 5. Shot List และไฟล์

25. ทุก Shot มีครบทุกช่องตาม engine/07 หัวข้อ 3 รหัส Shot ไม่ซ้ำ Clip ซ้ำได้เฉพาะ REUSE
26. ทุก Clip ใหม่มีไฟล์ prompt ครบตามที่ช่อง Image/Video Prompt ชี้ ชื่อไฟล์ตรงกัน ไม่มีไฟล์ prompt ที่ไม่มี Shot อ้างถึง
27. REUSE ระบุคลิปต้นทางและ marker จุดเข้า/ออก ไม่มีไฟล์ prompt
28. เวลาสั่งสร้างพอสำหรับบทเต็มและ Action เวลาใช้จริงไม่เกินเวลาสั่งสร้าง คลิปที่ยาวเกินขีดจำกัดของ Grok ถูกแบ่ง
29. Shot ของหน่วยตัดต่อเดียวกันอยู่ติดกัน

## 6. รูปแบบผลตรวจที่ส่งกลับ

```text
SC0x — ผลตรวจรอบ [n]
ต้องแก้:
- [Shot/Clip ID] [ไฟล์] — [ปัญหา] → [วิธีแก้ที่เสนอ] (ข้อ [เลข])
ควรแก้:
- ...
หมายเหตุ / ความเสี่ยงตอนผลิต:
- [เช่น มุมเงยชันเสี่ยงหน้าเพี้ยน, ข้อความไทยในภาพต้องตรวจตัวสะกด]
สรุป: ต้องแก้ [n] ข้อ / ควรแก้ [n] ข้อ
```

- `ต้องแก้` = ทำให้บท ตัวตน ผัง หรือรอยต่อผิด หรือ prompt ใช้แยกเดี่ยวไม่ได้
- `ควรแก้` = ไม่ผิดแต่ลดคุณภาพหรือเสี่ยง
- ระบุปัญหาให้เจาะจงพอที่ agent อื่นแก้ได้โดยไม่ต้องตรวจซ้ำทั้งไฟล์
- ถ้าไม่พบปัญหา ให้เขียน "ไม่พบปัญหาจากการตรวจเอกสาร" ไม่ใช้คำว่าผ่านการผลิต
