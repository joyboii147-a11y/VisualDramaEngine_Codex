# 07 — รูปแบบไฟล์

ทุกไฟล์เป็น UTF-8 เอกสารใช้ `.md` ส่วน prompt ใช้ `.txt` เปิดอ่านได้ด้วย Notepad

## 0. Input ที่ผู้ใช้เตรียมด้วยมือ

```text
input/
  story/
    EP01.txt                         ← เรื่องที่ Gemini แก้แล้ว หนึ่งไฟล์ต่อตอน
    EP02.txt
  characters/
    แพจีอา/                          ← ชื่อโฟลเดอร์ = ชื่อมาตรฐานในไฟล์เรื่อง
      W01_ชุดคลุมท้องม่วง.png        ← ภาพตัวละครในชุดที่ 1
      W01_ชุดคลุมท้องม่วง_หลัง.png   ← ไม่บังคับ: ด้านหลังของชุดที่ 1
      W02_สูทขาวงานเลี้ยง.png         ← ภาพตัวละครในชุดที่ 2
      face.png                        ← ไม่บังคับ: หน้าระยะใกล้
    มินฮยอก/
      W01_คาร์ดิแกนกรมท่า.png
```

**กฎการตั้งชื่อ**
- ชื่อโฟลเดอร์ตัวละคร = ชื่อมาตรฐานในรายชื่อตัวละครของไฟล์เรื่อง สะกดตรงกันทุกตัวอักษร
- ไฟล์ชุดขึ้นต้นด้วย `W` + เลขสองหลัก ตามลำดับที่ชุดปรากฏครั้งแรกในซีรีส์ ตามด้วย `_` และชื่อชุดสั้นๆ (ตั้งอิสระ ใช้ให้คนอ่านเข้าใจ)
- **เลขชุดของแต่ละตัวละครห้ามเปลี่ยน และห้ามนำเลขเดิมไปใช้กับชุดอื่น** เลขนี้คือ Wardrobe State ใน Bible (`แพจีอา W02` = `C01-W02`)
- `_หลัง` ต่อท้ายชื่อไฟล์ชุดเดิม สำหรับภาพด้านหลังของชุดนั้น
- `face.png` หน้าระยะใกล้ หนึ่งไฟล์ต่อตัวละคร
- รองรับ `.png` `.jpg` `.webp` ไม่ใส่ช่องว่างในชื่อไฟล์ ใช้ `_` แทน
- ตัวประกอบที่ไม่มีภาพ (แม่บ้าน 1, คนเดินผ่าน) ไม่ต้องมีโฟลเดอร์ ระบบจะใช้คำบรรยายแทน

**ภาพที่ดีสำหรับใช้อ้างอิง**
- ภาพชุด: เต็มตัวหรือถึงเข่า หันหน้าตรงหรือเกือบตรง หน้าชัด พื้นหลังเรียบ แสงกลางๆ มีคนเดียวในภาพ
- face.png: หน้าตรง ระยะไหล่ขึ้นไป หน้าชัด พื้นหลังเรียบ

**ไฟล์เรื่องจาก Gemini (`input/story/EPxx.txt`)** ทำตาม `Gemini_prompt_แกะคลิป.md` มีโครงดังนี้:

```text
ตอน: EP01
ใช้บทพูด: ตรงตัว   (หรือ: ใช้เพียงโครงเรื่อง)
ความยาวคลิป: 03:25
รายชื่อตัวละคร (ชื่อ — บทบาท — ชื่อเรียกอื่น — จุดสังเกต)

### ฉากที่ 1 — สถานที่ — เวลา — 00:06–00:58
ตัวละครพร้อมเลขชุด: ...
ผังฉาก: จุดสำคัญในพื้นที่ / กลุ่มคนและตำแหน่ง / คนที่อยู่แยก
[ช่วงเวลาต่อเนื่อง แต่ละช่วงมี: อยู่ในฉากตอนนี้ · เห็นในภาพ · การเคลื่อนที่ ·
 ทิศหน้าและสายตา · สิ่งที่เกิดขึ้น · ปฏิกิริยาของคนรอบข้าง · บทพูด · หน้าที่ในเรื่อง]
```

**ข้อมูลภาพในไฟล์เรื่องคือข้อเท็จจริงของผู้ใช้ เทียบเท่าบทพูด** ผังฉาก ตำแหน่ง การเดิน ปลายทาง ทิศสายตา และคนที่อยู่ในฉากแต่ไม่พูด ห้ามตัด ห้ามย้าย ห้ามแต่งใหม่

**ไฟล์เรื่องแบบเก่า** (มีแค่บทพูดกับวงเล็บสั้นๆ ไม่มีผังฉาก) ยังรับได้ แต่ระบบต้องเดาตำแหน่งเกือบทั้งหมด ให้ agent หลักบันทึกในไฟล์สมมติฐานบรรทัดแรกว่า "ไฟล์เรื่องไม่มีผังฉาก ตำแหน่งตัวละครเป็นการเดาทั้งหมด ควรแกะคลิปใหม่ด้วย Gemini_prompt_แกะคลิป.md"

ถ้าไฟล์เรื่องไม่ระบุเลขชุด ให้ `bible` จับคู่ชุดจากคำบรรยายกับภาพในโฟลเดอร์ตัวละคร และบันทึกการจับคู่เป็นสมมติฐาน

- บทพูด / เสียง: D003 มิน: "มีสิ แต่เธอไม่เคยถามฉัน" | โหมด A

- เวลาใช้จริง / จุดตัด / Continuity: ~5 วิ | In: มือบนตัก มองขวาเฟรม ปากปิด → Out: ปากปิด สายตาเดิม | ตัดหลังพักสั้นๆ | ภาพใหม่ในฉากเดิม | Blocking: SC01-B03
- Clip: A005 — คลิปหลัก (A-roll) | EP01_A005_T01.mp4 | [หมายเหตุ เช่น เหตุผลแยกตัวละคร ความเสี่ยง]
- แนบใน OpenArt: 1) input/characters/มิน/face.png
- แนบใน Grok: ภาพที่เลือกจาก EP01_A005_image

```

v68: ช่องตัวละครที่เห็นระบุลำดับเฟรมซ้าย→ขวา (คัดลอกจาก Setup Map) และช่อง Continuity ปิดท้ายด้วย `Blocking: <แถวใน Blocking Table>`

10 ช่องแรก (Shot ID ถึง Video Prompt ไม่นับสองช่อง "แนบใน") ตรงกับตาราง 10 คอลัมน์ที่ผู้ใช้กำหนด ส่วนสองช่อง "แนบใน" บอกผู้ใช้ว่าต้องอัปโหลดภาพอะไรตามลำดับไหน

**บล็อก REUSE**

## EP01-S003
- Scene/Beat: SC01 / SC01-B01
- หน้าที่: กลับไปเห็นความผิดหวังของส้ม
- ตัวละครที่เห็น / ผู้พูด: ส้ม C03-W01 (1 คน) / ส้ม ON
- บทพูด / เสียง: D001 ช่วง 3/3 ส้ม: "ว่าคุณจะไม่ไปงานเลี้ยง" | เสียงจาก A001 ต่อเนื่อง
- เวลาสั่งสร้าง: ไม่สร้างใหม่
- เวลาใช้จริง / จุดตัด / Continuity: ~2 วิ | เข้าที่คำว่า "ว่าคุณ" ออกหลังจบประโยค | กลับ A001 ตามเวลาเดิม ไม่เริ่มใหม่
- Clip: REUSE A001
- แนบใน OpenArt: –
- แนบใน Grok: –
- Image Prompt: ไม่สร้างภาพใหม่ — ใช้ภาพจาก A001 ช่วงที่ระบุ

```

**ทุก Clip ใหม่ใช้บล็อกแบบเดียวกัน** มีภาพแนบใน OpenArt, "แนบใน Grok: ภาพที่เลือกจาก EPxx_Axxx_image" และไฟล์ prompt ครบทั้งสองไฟล์ คลิปที่ต่อการกระทำจากคลิปก่อนระบุไว้ในช่อง Continuity เท่านั้น เช่น `ต่อการกระทำจาก A007 — ตัดจาก Medium เป็น CU`

- คั่นกลุ่ม Shot ที่ไม่เกี่ยวกันด้วยเส้น `---` Shot ของหน่วยตัดต่อเดียวกันวางติดกัน
- Optional Coverage อยู่ท้ายไฟล์ใต้หัวข้อ `## Optional Coverage` ไม่มีไฟล์ prompt

## 4. ไฟล์ prompt `.txt`

ทุกไฟล์มีสองส่วน แยกด้วยบรรทัดคั่นตายตัว

**ส่วนที่ 1 — หมายเหตุสำหรับผู้ใช้ (ภาษาไทย ทุกบรรทัดขึ้นต้นด้วย `#`)** ไม่ก๊อปไปใช้
**ส่วนที่ 2 — prompt** ภาษาอังกฤษตามแม่แบบ engine/03 หรือ engine/04 ผู้ใช้ก๊อปตั้งแต่บรรทัดใต้เส้นคั่นจนจบไฟล์

```text
# ==================== หมายเหตุ — ไม่ต้องก๊อป ====================
# Shot: EP25-26-S012 | Clip: A012 (A-roll) | SC03 ห้องรับประทานอาหาร กลางวัน
# ไฟล์นี้: Image Prompt → OpenArt GPT Image 2 (9:16)
#
# ตัวละครในเฟรม (รวม [n] คน):
# - แพจีอา  C01-W02 สูทขาวงานเลี้ยง      | เต็มตัว หันหน้าหากล้อง กลางเฟรม
# - มินฮยอก C02-W01 คาร์ดิแกนกรมท่า     | เห็นแค่ไหล่ซ้ายและท้ายทอย หันหลัง ขอบขวา (OTS)
# - แม่บ้าน 1 (ไม่มีภาพอ้างอิง)          | เห็นแค่มือที่ถือถาด ขอบล่างซ้าย
#
# เกี่ยวข้องแต่ไม่อยู่ในเฟรม:
# - ฮียอน   C03-W01 สูทขาวขอบดำ         | นอกเฟรมขวา เป็นคนที่แพจีอามอง
#
# แนบใน OpenArt: 1) input/characters/แพจีอา/W02_สูทขาวงานเลี้ยง.png
#                2) input/characters/มินฮยอก/W01_คาร์ดิแกนกรมท่า_หลัง.png
# ==================== ก๊อปตั้งแต่บรรทัดถัดไป ====================
Create one standalone starting-frame image for SHOT EP25-26-S012.
...
```

**กฎของส่วนหมายเหตุ**
- **"ตัวละครในเฟรม"** ต้องมีทุกคนที่เห็น**ส่วนใดส่วนหนึ่ง**ในภาพ ไม่ว่าจะหันหลัง เห็นแค่มือ ไหล่ ผม ขา เงา เงาสะท้อนในกระจก คนเบลอในฉากหลัง หรือคนที่อยู่บนจอโทรศัพท์ จำนวนรวมต้องตรงกับ CAST COUNT ใน prompt
- ทุกคนระบุ: ชื่อมาตรฐาน · รหัสชุด + ชื่อชุดตามชื่อไฟล์ภาพ (ไม่มีภาพเขียน "ไม่มีภาพอ้างอิง" ตัวประกอบไม่มีรหัสชุดให้บรรยายชุดสั้นๆ) · ส่วนที่เห็นและทิศที่หัน · ตำแหน่งในเฟรม
- ส่วนที่เห็นใช้คำเหล่านี้ให้สม่ำเสมอ: `เต็มตัว` `ครึ่งตัว` `หน้า (CU)` `หันหลัง` `ด้านข้าง` `เห็นแค่[ส่วน]` `เบลอฉากหลัง` `เงาสะท้อน` `บนจอ`
- **"เกี่ยวข้องแต่ไม่อยู่ในเฟรม"** ได้แก่ คนที่ตัวละครในเฟรมกำลังมองหรือคุยด้วย คนที่พูด OS หรือ VO และคนที่อยู่ในฉากแต่นอกกรอบภาพ ถ้าไม่มีให้เขียน "ไม่มี"
- **ไฟล์ video** ใช้รูปแบบเดียวกัน เปลี่ยนบรรทัด "ไฟล์นี้" เป็น `Video Prompt → Grok Imagine | ยาว [n] วิ | เสียงโหมด [A/B/C]` เปลี่ยน "แนบใน OpenArt" เป็น "แนบใน Grok" และเพิ่ม `# ผู้พูด: [ชื่อ ON/OS/VO] | คนในเฟรมที่ไม่พูด: [ชื่อ]` คนที่**เดินเข้าเฟรมระหว่างคลิป**ให้อยู่ในรายการตัวละครในเฟรมพร้อมระบุ "เข้าเฟรมช่วงท้าย"
- ข้อมูลในหมายเหตุต้องตรงกับไฟล์ Shot และ prompt ด้านล่างทุกจุด ห้ามมีข้อมูลที่ prompt ไม่มี
- บรรทัดคั่นสองเส้นต้องเหมือนตัวอย่างทุกตัวอักษร
- ใต้เส้นคั่นเป็นภาษาอังกฤษล้วน ไม่มีบรรทัด `#` หรือภาษาไทยนอกจากบทพูดในเครื่องหมายคำพูด
- หนึ่งไฟล์ = หนึ่งคำขอ ไม่รวมหลายคลิปในไฟล์เดียว
