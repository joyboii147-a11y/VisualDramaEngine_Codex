# 06 — สถานะงานและสถานะเรื่อง (`state_keeper`)

เอกสารสถานะมีสองใบ หน้าที่ต่างกัน ห้ามใช้แทนกัน

| เอกสาร | ตอบคำถาม |
|---|---|
| `state/project_state.md` | งานผลิตเอกสารทำถึงตอนไหน ไฟล์ไหนเสร็จ อะไรค้าง |
| `state/story_state_ล่าสุด.md` | เรื่องดำเนินมาถึงจุดไหน ใครรู้อะไร ใครอยู่ที่ไหน ใส่ชุดอะไร |

ความต่อเนื่องระหว่าง Shot อยู่ในช่อง Continuity ของแต่ละ Shot ไม่อยู่ในสองใบนี้

## 1. Project State

อัปเดตเมื่อจบตอน หรือเมื่อแก้งานที่เปลี่ยนสถานะ

```text
PROJECT STATE
Rule Version: VisualDramaEngine v67 Codex
Series: [ชื่อเรื่อง]
ตอนล่าสุดที่ทำ: EP[xx]
ตอนที่เสร็จครบ: [รายการ]
EP[xx]: Shot [n] / Clip ใหม่ [n] / REUSE [n] / เวลาหนังประมาณ [n] วิ
ต้องแก้ค้าง (จาก 04_review.md): [จำนวนและรายการสั้น หรือ "ไม่มี"]
สมมติฐานที่รอผู้ใช้ตัดสิน: [รายการสั้น หรือ "ไม่มี"]
Bible ล่าสุด: ตัวละคร [n] คน / Wardrobe State [n] ชุด / สถานที่ [n] แห่ง
ถัดไป: [งานถัดไปหนึ่งข้อ]
```

- ใช้เฉพาะสถานะที่เกิดขึ้นจริงในไฟล์ ไม่เขียนว่าภาพหรือวิดีโอผ่าน
- แก้เฉพาะส่วนที่ได้รับผล ไม่รีเซ็ตตอนอื่น

## 2. Story State Sheet

ทำทุกครั้งเมื่อแตก Shot ครบทั้งตอน หรือเมื่อผู้ใช้สั่ง "สรุปสถานะ", "ปิดตอน", "ทำใบสถานะ"

- ทำเป็น **ภาพรวมเต็ม** ไม่ใช่เฉพาะสิ่งที่เปลี่ยน ข้อมูลที่ไม่เปลี่ยนให้คัดลอกต่อจากใบก่อน
- ก่อนเขียนทับ `state/story_state_ล่าสุด.md` ให้คัดลอกใบเดิมไปเก็บที่ `state/archive/story_state_EP[ตอนก่อน].md`
- ตอนใหม่เริ่มจากใบล่าสุดนี้ ไม่ต้องอ่านบทหรือ Shot ของตอนเก่าทั้งหมด

```text
STORY STATE — จบ EP[xx]
Rule Version: VisualDramaEngine v67 Codex
Story: [ชื่อเรื่อง]
Story Time ณ จบตอน: [วัน/ช่วงเวลาในเรื่อง เช่น "คืนวันที่ 3 หลังงานเลี้ยง"]
ที่มาของข้อมูล: [บทจากผู้ใช้ / Shot List EP[xx] / ผลจริงที่ผู้ใช้แจ้ง]

1) ตัวละคร ณ จบตอน
| รหัส | ชื่อ | อยู่ที่ | Wardrobe State | สภาพร่างกาย/รูปลักษณ์ที่เปลี่ยน | สภาพอารมณ์ค้าง |
|---|---|---|---|---|---|

2) ความลับและความรู้ (ใครรู้อะไร)
| ความลับ/ข้อเท็จจริง | รู้แล้ว | สงสัย | ยังไม่รู้ | รู้ตั้งแต่ EP |
|---|---|---|---|---|

3) ความสัมพันธ์
| คู่ตัวละคร | สถานะปัจจุบัน | เปลี่ยนในตอนนี้อย่างไร |
|---|---|---|

4) พร็อพที่ยังมีผลต่อเรื่อง
| รหัส | สิ่งของ | อยู่ที่/อยู่กับใคร | สภาพ |
|---|---|---|---|

5) ปมเรื่อง
- ยังเปิดอยู่: [ปมที่ปูไว้และยังไม่จ่าย พร้อม EP ที่เริ่ม]
- ปิดแล้วในตอนนี้: [ปมที่คลี่คลาย]

6) Hook ท้ายตอน → สิ่งที่ตอนถัดไปต้องรับต่อ
[ภาพหรือบทสุดท้ายของตอน และสถานะที่ฉากแรกของตอนถัดไปต้องเริ่มจาก]

7) สิ่งที่เพิ่มหรือเปลี่ยนใน Bible ระหว่างตอนนี้
[ตัวละครใหม่ / Wardrobe State ใหม่ / สถานที่ใหม่ หรือ "ไม่มี"]
```

**กฎ**
- บันทึกเฉพาะสิ่งที่เกิดขึ้นจริงในบทและ Shot List ของตอน ไม่แต่งเหตุการณ์เพิ่ม
- ถ้าผู้ใช้แจ้งผลจริงที่ต่างจากแผน (เช่น ชุดในคลิปที่เลือกใช้ต่างไป ของหาย) ให้ยึดผลจริงที่ผู้ใช้แจ้ง และระบุใน "ที่มาของข้อมูล"
- ใช้รหัส `C01` / `C01-W01` / `L01` / `P01` ตาม Bible ไม่ตั้งชื่อชุดใหม่ซ้ำซ้อน ไม่คัดลอก Identity Block มาไว้ในใบนี้
- ตาราง "ใครรู้อะไร" แยก **รู้แล้ว / สงสัย / ยังไม่รู้** ให้ชัด
- ใส่เฉพาะพร็อพ ปม ความสัมพันธ์ที่ยังมีผลต่อเรื่อง ของที่จบบทบาทแล้วตัดออก
- ใบนี้ไม่แก้ Bible เอง ถ้าเรื่องทำให้ Bible ต้องเปลี่ยน ใส่ในข้อ 7 และรายงานกลับ

## 3. ตรวจเมื่อเริ่มตอนใหม่

`breakdown` และ `bible` ตรวจกับใบสถานะล่าสุดก่อนเริ่มงาน แล้วรายงานความขัดแย้ง:

1. ฉากแรกต่อจาก Hook ท้ายตอนก่อนได้ หรือบทระบุการข้ามเวลาชัดเจน
2. ตัวละครอยู่ในสถานที่และ Wardrobe State ที่ต่อจากใบสถานะได้ การเปลี่ยนชุดต้องมีการเปลี่ยนเวลาหรือการกระทำรองรับ
3. สภาพร่างกายที่ค้าง (แผล ผมเปียก รอยน้ำตา) ยังอยู่ หรือมีเวลาผ่านไปพอให้หาย
4. บทพูดและการแสดงไม่ขัดกับตาราง "ใครรู้อะไร"
5. พร็อพที่ยังมีผลอยู่ถูกที่และถูกคน

ถ้าพบความขัดแย้ง ให้เลือกวิธีแก้ที่ไม่เปลี่ยนบท (เช่น ใช้ชุดตามใบสถานะ เพิ่ม Shot อธิบาย) บันทึกเป็นสมมติฐาน แล้วทำต่อ ห้ามแก้ใบสถานะย้อนหลังให้ตรงกับตอนใหม่โดยไม่มีคำสั่งผู้ใช้

## 4. สิ่งที่ส่งกลับให้ agent หลัก

- ไฟล์ที่เขียนและไฟล์ที่เก็บเข้า archive
- รายการเปลี่ยนแปลงใน Bible ที่รอยืนยัน (ข้อ 7)
- ความขัดแย้งที่พบระหว่างตอนนี้กับใบสถานะเดิม
