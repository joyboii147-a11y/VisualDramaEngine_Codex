# ดึง Prompt ของตอน

อาร์กิวเมนต์: เลขตอน เช่น `EP28` หรือ `EP25-26` (ชื่อโฟลเดอร์ตอนตรงตัว)

## ขั้นตอน
1. ตรวจว่ามี `EPxx/shots/SC*.md` และ `EPxx/prompts/` ถ้าไม่มี แจ้งว่า "ตอนนี้ยังไม่มี prompt ต้องรันขั้นเขียน prompt (Codex ตาม AGENTS.md) ก่อน" แล้วหยุด
2. รันจากโฟลเดอร์โปรเจกต์:
   ```
   python .claude/skills/vde-episode/scripts/collect.py EPxx
   python .claude/skills/vde-episode/scripts/state.py EPxx budget
   ```
3. รายงานสั้นๆ: จำนวน Shot / Clip ใหม่ / REUSE / วินาทีวิดีโอรวม / ภาพอ้างอิงที่ต้องอัปโหลด / เครดิตและเงินโดยประมาณ / บรรทัดที่ขึ้นต้นด้วย `!` (ปัญหา) ทุกบรรทัด

## สิ่งที่สคริปต์ทำ
- อ่านบล็อก `## EPxx-Snnn` ทุกไฟล์ Shot ตามลำดับ Scene: เลข Clip, REUSE, เวลาสั่งสร้าง, เวลาใช้จริง, บทพูด (คำต่อคำ), โหมดเสียง, "ปิดเสียง", "ทับช่วง"
- อ่านหัวไฟล์ prompt: บรรทัด `แนบใน OpenArt:` (สูงสุด 4 ภาพ) และ `ยาว n วิ` (ปัดขึ้นเป็นจำนวนเต็ม 1–15 สำหรับ Grok)
- รันซ้ำได้ปลอดภัย: สถานะเดิมคงอยู่ คลิปที่ไฟล์ prompt ถูกแก้จะถูกรีเซ็ตเป็น `todo` (ถ้าภาพเปลี่ยน วิดีโอรีเซ็ตด้วย)
- ไม่แตะไฟล์ใน `input/` และไม่แก้ไฟล์ prompt/Shot
