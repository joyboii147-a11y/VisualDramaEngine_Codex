# แกะคลิป (ขั้นก่อน Step 0 ของ AGENTS.md)

อาร์กิวเมนต์: `EPxx` และถ้ามี: ชื่อไฟล์วิดีโอ, รุ่นโมเดล, "แล้วทำต่อเลย"
ทุกคำสั่งรันจากโฟลเดอร์โปรเจกต์ ตั้ง `PYTHONIOENCODING=utf-8` · `D=.claude/skills/vde-decode/scripts/decode.py`
ใช้ fal key เดียวกับ vde-images (DPAPI) ห้ามพิมพ์ key

ไฟล์งานทั้งหมดอยู่ที่ `Source/EPxx_แกะคลิป/` (prompt, วิดีโอบีบ 540p, `EPxx.txt`, `frames/`, `meta.json`, `usage_*.json`)
**ไม่เขียน `input/` จนกว่าผู้ใช้สั่งย้าย** (AGENTS.md ข้อ 7.9) ยกเว้นผู้ใช้สั่ง "แกะคลิป EPxx แล้วทำต่อเลย"

## คำสั่งย่อย
| ผู้ใช้สั่ง | ทำ |
|---|---|
| "แกะคลิป EPxx" / "แกะเนื้อเรื่อง EPxx" / "แกะเหตุการณ์ EPxx" | ขั้น 1–6 โหมด `full` (เนื้อเรื่อง เหตุการณ์ บทพูด ได้จากการส่งวิดีโอครั้งเดียว ถ้าแยกส่งจะเสียเงินซ้ำ) |
| "แกะบทพูด EPxx" | ขั้น 1–2 โหมด `dialogue` → `EPxx_บทพูด.txt` ใช้ตรวจทานบทพูดของไฟล์หลัก แล้วทำขั้น 7 |
| "ตรวจไฟล์แกะคลิป EPxx" | ขั้น 4 อย่างเดียว |
| "ย้าย EPxx เข้า input" | ขั้น 8 |
| "แกะคลิป EPxx แล้วทำต่อเลย" | ขั้น 1–6 แล้วขั้น 8 แล้วทำตาม AGENTS.md ข้อ 5 ทันที |

## ขั้นตอน
1. **เตรียม** `python $D EPxx prep [--video "Source/<ไฟล์>.mp4"] [--mode full|dialogue]`
   หาไฟล์ `Source/*EPxx*.mp4` เอง (เจอไม่ใช่ 1 ไฟล์ → ถามผู้ใช้ เป็นจุดหยุดเดียว) บีบวิดีโอ หาจุดตัดภาพ ดึงรายชื่อตัวละครจากไฟล์เรื่องตอนก่อน แล้วรวมกับ `task_full.md` + `Claude_prompt_แกะคลิป.md` เป็น prompt
2. **ส่งแกะ** `python $D EPxx run [--mode ...] [--model google/gemini-3.1-pro-preview]`
   ค่าเริ่มต้น gemini-3.1-pro-preview (ต้อง reasoning true — สคริปต์ใส่ให้) ราคาราว $0.3 ต่อคลิป 2 นาที ดู `usage_*.json`
   ไฟล์ผลมีอยู่แล้ว → สคริปต์ไม่ทับ ต้องใช้ `--force` เฉพาะเมื่อผู้ใช้สั่งแกะใหม่
   error 403 / Exhausted balance → หยุด รายงานให้เติมเงินที่ fal.ai/dashboard/billing
3. **ภาพอ้างอิง** `python $D EPxx frames` → ดึงภาพกลางช็อตทุกช็อตลง `frames/EPxx_Sxxx.jpg`
4. **ตรวจ** `python $D EPxx check` → ช็อตทับ/เว้นช่อง, จำนวนช็อตไม่ตรงหัวไฟล์, ฉากทับกัน, ช็อตสุดท้ายไม่ถึงท้ายคลิป, จำนวนป้าย [ตรวจเสียง] [ภาพไม่ชัด] [ฟังไม่ชัด] [ตัวละครใหม่] W??, ชื่อที่ไม่อยู่ในรายชื่อ, ชุดที่ยังไม่มีภาพ
5. **แก้เอง** (agent หลักแก้ด้วย Edit) เฉพาะปัญหาเชิงโครงสร้างจากขั้น 4: เวลาช็อต/ฉากทับกัน (ยึดจุดตัดใน `meta.json` และเปิดภาพ frames ดู) จำนวนช็อตในหัวไฟล์ แล้วรันขั้น 4 ซ้ำจนไม่มี problems
   **ห้ามแก้บทพูด** และห้ามเปลี่ยนเนื้อเหตุการณ์จากที่ Gemini เห็น ถ้าสงสัยให้ติด `[ตรวจเสียง: ...]` / `[ภาพไม่ชัด: ...]`
   **ตรวจภาพเทียบข้อความ (v68.2):** ถ้ามีตั้งแต่ 3 ฉากหรือเกินราว 30 ช็อต ให้ spawn sub-agent (general-purpose) หนึ่งตัวต่อฉากพร้อมกัน คำสั่ง: "อ่าน `Source/EPxx_แกะคลิป/EPxx.txt` เฉพาะฉากที่ n เปิดภาพ `frames/EPxx_Sxxx.jpg` ทุกช็อตของฉากนั้นด้วย Read เทียบกับหัวช็อต (ขนาดภาพ ตำแหน่งคนในเฟรม ชุด การกระทำ) ห้ามแก้ไฟล์ ส่งกลับเฉพาะรายการ: ช็อตที่ภาพไม่ตรงข้อความ (ระบุว่าภาพตรงกับช็อตไหนแทน ถ้าดูออก), ตัวละครที่ชื่อ/ชุดดูผิด, เวลาที่ควรขยับ" แล้ว agent หลักแก้ไฟล์เองคนเดียวตามผลรวม
   ตอนสั้นกว่านั้น agent หลักเปิดดูเอง อย่างน้อยช็อตแรก/สุดท้ายของแต่ละฉาก และช็อตที่ติดป้าย
   ภาพที่เลื่อนจากช็อตที่ชื่อบอก (เวลาของ Gemini คลาด) และแก้เวลาไม่ได้ ให้บันทึกในหมายเหตุหัวไฟล์
6. **รายงานผู้ใช้** สั้นๆ: จำนวนฉาก/ช็อต/ประโยค ค่าใช้จ่าย ปัญหาที่แก้ ป้ายตรวจที่เหลือ ชื่อต่างภาษาที่ยังอยู่ในบท ตัวละครใหม่ ชุดที่ยังไม่มีภาพ และเสนอคำสั่งถัดไป: `vde-rename` (เปลี่ยนชื่อ), `vde-wardrobe` (ทำภาพชุด), "ย้าย EPxx เข้า input"
7. **(โหมด dialogue)** เทียบ `EPxx_บทพูด.txt` กับบทใน `EPxx.txt` รายงานประโยคที่ต่างกัน ถ้าผู้ใช้สั่งให้ใช้ฉบับใหม่ จึงแก้บทในไฟล์หลักทีละประโยค
8. **ย้ายเข้า input** `python $D EPxx promote` → ย้ายเป็น `input/story/EPxx.txt` (ไม่ทับไฟล์เดิมถ้าไม่มี `--force`) และเติมหมายเหตุตำแหน่ง frames ไว้ใต้ช่อง "ที่มา" ภาพ frames อยู่ที่เดิม

## กฎ
- บทพูดในไฟล์ถือเป็นฉบับถอดเสียง ไม่ใช่บทที่ผู้ใช้ยืนยัน: ในขั้นเขียน prompt ให้บันทึกใน `EPxx/00_สมมติฐาน.md` ว่า "ต้องให้ผู้ใช้ฟังยืนยันบทพูด" เสมอ
- ไม่ส่งวิดีโอซ้ำโดยไม่จำเป็น — แต่ละครั้งเสียเงิน
