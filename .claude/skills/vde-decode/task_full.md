คำสั่งเฉพาะงานนี้ (มาก่อนคำแนะนำด้านล่างเมื่อขัดกัน):
- วิดีโอที่แนบคือ ละครสั้นตอน {ep} ความยาว {dur} คุณดูภาพและฟังเสียงได้โดยตรง ไม่ต้องดึงภาพนิ่ง ข้ามหัวข้อ "วิธีดูวิดีโอ" ส่วนที่เป็นคำสั่ง ffmpeg ได้ แต่กฎการบันทึกยังใช้ทุกข้อ
- งานนี้มี 3 ส่วนในไฟล์เดียว: (1) เนื้อเรื่อง — ผังฉากและช่วงเรื่องของแต่ละฉาก (2) เหตุการณ์ — ทุกช็อตต้นฉบับพร้อมการกระทำตั้งแต่เฟรมแรกถึงเฟรมสุดท้าย (3) บทพูด — ถอดจากเสียงแบบคำต่อคำ วางในช่วงเรื่องและในช็อตที่พูด
- ผู้ใช้ไม่ได้ให้ไฟล์บทพูดมา ให้ถอดบทพูดจากเสียงในคลิปเองแบบคำต่อคำในภาษาที่ได้ยิน ถ้าเป็นภาษาเกาหลีหรือภาษาอื่น ให้ถอดต้นฉบับแล้วตามด้วยคำแปลไทยในวงเล็บ ถ้ามีซับไทยบนจอ ให้ใช้ข้อความซับไทยเป็นบทพูดหลัก คำที่ฟังไม่ชัดให้ใส่ [ฟังไม่ชัด]
- ช่อง "ที่มา" ให้เขียน: ภาพและบทพูด — Gemini ผ่าน fal openrouter/router/video (คลิป {video})
- ช่อง "ภาพอ้างอิง" ให้เขียน frames/{ep}_Sxxx.jpg ตามรหัสช็อต (ระบบจะดึงภาพเองภายหลัง)
- หัวช็อตต้องเป็นรูปแบบ "#### Sxxx · mm:ss.s–mm:ss.s · Setup ..." และหัวฉากเป็น "### ฉากที่ n — สถานที่ — เวลา — mm:ss.s–mm:ss.s" เวลาช็อตต้องต่อกันพอดี ไม่ทับกัน ไม่เว้นช่อง และฉากถัดไปเริ่มเมื่อฉากก่อนจบ
- จุดตัดภาพที่ ffmpeg ตรวจได้ (วินาที, scene>0.25) มี {ncut} จุด: {cuts}
  ใช้เป็นจุดตั้งต้นแบ่งช็อต ตรวจกับภาพจริง จุดที่ไม่ใช่การตัดภาพ (เช่น แฟลช การเคลื่อนไหวเร็ว) ให้รวม จุดตัดที่ตกหล่นให้เพิ่ม เวลาช็อตเขียนละเอียดถึง 0.1 วินาที
- ชื่อตัวละครให้ใช้ชื่อมาตรฐานตามรายชื่อจากตอนก่อน ({prev}) ด้านล่าง ถ้าในเสียงเรียกชื่อต่างภาษา ให้แปลงเป็นชื่อมาตรฐานตามชื่อเรียกอื่นที่ระบุ ตัวละครที่ไม่อยู่ในรายชื่อให้ติด [ตัวละครใหม่] เลขชุดถ้าชุดตรงกับที่บรรยายไว้ให้ใช้เลขเดิม ชุดใหม่เขียน W?? ไว้ให้ผู้ใช้กำหนด
- บทพูดในช่วงเรื่องเขียนเป็น ชื่อ (Wxx): "ข้อความ" หนึ่งประโยคต่อบรรทัด เสียงนอกภาพหรือเสียงในใจให้ระบุในวงเล็บหลังเลขชุด
- คลิปอาจมีลายน้ำ ข้อความบนจอ หรือภาพย่อซ้อน ให้บันทึกไว้ในหมายเหตุหัวผลลัพธ์ว่าไม่ใช่ส่วนของฉาก
- ตอบเป็นเนื้อไฟล์ {ep}.txt อย่างเดียว ไม่ต้องมีคำนำหรือ code fence ต้องครบทุกช็อตจนจบคลิป ห้ามย่อหรือข้าม
