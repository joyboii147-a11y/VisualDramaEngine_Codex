# ภาพชุดตัวละคร

ทุกคำสั่งรันจากโฟลเดอร์โปรเจกต์ ตั้ง `PYTHONIOENCODING=utf-8` · `W=.claude/skills/vde-wardrobe/scripts/wardrobe.py`
การสร้างภาพลง `input/characters/` เป็นการเขียน input — ทำเฉพาะเมื่อผู้ใช้สั่ง (คำสั่งนี้ถือว่าสั่งแล้ว) สคริปต์ไม่ทับไฟล์เดิมเสมอ

## ขั้นตอน
1. **หาชุดที่ขาด** `python $W EPxx plan` → รายการ (ตัวละคร, Wxx) ที่ใช้ในไฟล์เรื่องแต่ยังไม่มีภาพ พร้อมไฟล์หน้า (`Face.*`) และช็อตที่ชุดนั้นปรากฏ
   ไฟล์เรื่องยังมี `W??` → กำหนดเลขชุดใหม่ก่อน: เลขถัดจากเลขสูงสุดในโฟลเดอร์ตัวละครนั้น แก้ในไฟล์เรื่องให้ตรง แล้วรัน plan ใหม่
2. **เลือกภาพนิ่งอ้างอิง** เปิด `Source/EPxx_แกะคลิป/frames/EPxx_Sxxx.jpg` ของช็อตในรายการด้วย Read เลือก 2–4 ภาพที่เห็นชุดชัด (เต็มตัว/ครึ่งตัว ด้านหน้าและด้านหลังถ้ามี) ภาพเลื่อนช็อตได้ ให้ดูภาพจริง ไม่ใช่ชื่อไฟล์
   ต้องการภาพที่ไม่มีในโฟลเดอร์ frames → ดึงเพิ่มด้วย `ffmpeg -ss <วินาที> -i <วิดีโอ> -frames:v 1 -vf scale=540:-2 Source/EPxx_แกะคลิป/frames/EPxx_<ชื่อ>.jpg` แล้วอ้างชื่อนั้นใน jobs (ส่วนหลัง `EPxx_`)
3. **เขียน jobs.json** ใน scratchpad:
   ```json
   [{"character": "วิทย์", "wardrobe": "W08", "label": "แจ็กเก็ตหนังกลับน้ำตาล",
     "outfit": "<คำบรรยายชุดภาษาอังกฤษจากภาพจริง: ชิ้นนอก→ชิ้นใน สี วัสดุ เครื่องประดับ รองเท้า ทรงผม>",
     "frames": ["S085", "S087"]}]
   ```
   - `label` ภาษาไทยสั้นๆ ชื่อไฟล์ออกมาเป็น `<ชื่อ> <Wxx> <label>.png`
   - ตัวละครไม่มีรูปหน้า (ตัวประกอบ การ์ด) ให้ใส่ `"person"` บรรยายอายุ ผิว รูปร่าง ทรงผม ให้ต่างกันชัดเจนระหว่างตัวประกอบชุดเดียวกัน สคริปต์จะสร้างหน้าใหม่และสั่งห้ามลอกหน้านักแสดงในคลิป
   - ตัวละครที่มีภาพชุดเก่าใกล้เคียง (เช่น สูททรงเดิมแต่เปลี่ยนเนกไท) ให้ระบุในคำบรรยาย
4. **สร้าง** `python $W EPxx gen <jobs.json> [--quality high]` (ค่าเริ่มต้น high 2048x1152) ส่งพร้อมกันทุกงานแล้วรอดาวน์โหลด
   error 403 / Exhausted balance → หยุด รายงานให้เติมเงิน
5. **ตรวจทุกภาพ** ด้วย Read: คนเดียวกัน 3 มุม ไม่มีตัวหนังสือ ชุดตรงกับภาพนิ่ง หน้าตรงกับ Face (หรือหน้าตัวประกอบแต่ละคนไม่ซ้ำกัน) ไม่ผ่าน → ลบไฟล์นั้นแล้วสร้างใหม่ได้อีก 1 ครั้ง (บอกผู้ใช้ว่าลบอะไร)
6. **อัปเดตเอกสาร** ถ้าทำหลังขั้นเขียน prompt แล้ว: `bible/ตัวละคร.md` (บรรทัด "ภาพ:" ของชุดนั้น), ตารางชุดใน `EPxx/03_setup_map.md`, หัวไฟล์ "แนบใน OpenArt" และบรรทัด `Image n:` ใน `EPxx/prompts/*_image.txt` ที่ตัวละครนั้นอยู่ในเฟรม (ไม่เกิน 8 รูปแนบ) แล้วรัน `python .claude/skills/vde-episode/scripts/collect.py EPxx` ให้คลิปที่แก้ถูกรีเซ็ต บันทึกใน `EPxx/00_สมมติฐาน.md`
   ถ้ายังไม่ได้ทำเอกสารตอน ให้แก้รายชื่อตัวละครในหัวไฟล์เรื่องให้ชี้ภาพใหม่ (`— ภาพ input/characters/...`)
7. **รายงาน** รายชื่อภาพที่สร้าง และบอกว่าภาพไหนเป็นหน้าที่สร้างใหม่ (ไม่มี Face) ให้ผู้ใช้เปิดดู
