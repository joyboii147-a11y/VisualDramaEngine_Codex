# ผลิตตอน (ตัวสั่งงานหลัก)

อาร์กิวเมนต์: `EPxx` (ชื่อโฟลเดอร์ตอน) และถ้ามี: ชื่อไฟล์เพลง, "ไม่เอาซับ", "ถึงแค่ภาพ"
ทุกคำสั่งรันจากโฟลเดอร์โปรเจกต์ · `S=.claude/skills/vde-episode/scripts` · ค่าตั้ง: `config.json` ในโฟลเดอร์นี้

**โหมดทำงาน:** ทำจนจบโดยไม่ถามระหว่างทาง (ผู้ใช้อาจสั่งแล้วทิ้งไว้ข้ามคืน) หยุดเฉพาะกรณีในหัวข้อ "จุดหยุด" งานนี้รันซ้ำได้ — ทุกขั้นข้ามคลิปที่ทำเสร็จแล้ว

## ขั้น 1 — ตรวจ input และดึง prompt
1. ถ้าไม่มี `EPxx/shots/` หรือ `EPxx/prompts/`: ถ้ามี `input/story/EPxx.txt` ให้แจ้งว่า "ต้องรันขั้นเขียน prompt ตาม AGENTS.md ก่อน" ถ้าไม่มีไฟล์เรื่องแต่มีคลิปใน `Source/` ให้แจ้งว่า "สั่ง แกะคลิป EPxx (skill vde-decode) ก่อน" ถ้าไม่มีทั้งคู่ แจ้งว่าไม่พบตอนนี้ → หยุด
2. ใช้ skill `vde-collect` (หรือรัน `python $S/collect.py EPxx` ตรงๆ) จดปัญหาที่ขึ้น `!` ไว้ใส่รายงาน

## ขั้น 2 — ตรวจงบและเครื่องมือ
1. `python $S/state.py EPxx budget`
2. ภาพ: ถ้า `image_provider` = `fal` → `python $S/fal_image.py check` (ไม่พบ key → **หยุด** แนะนำ set-fal-key) ถ้า `openart` → `openart_model_list` ดู `balance` ถ้า balance < `openart_credits_first_pass` → **หยุด** รายงานยอดที่ต้องใช้ ยอดที่มี และ upgradeUrl
3. `grok_list_models` → ถ้า error ให้จดว่า "ขั้นวิดีโอข้าม: grok ใช้ไม่ได้ (<ข้อความ>)" แล้วทำสาย Scene ถึงข้อ B แต่ข้ามข้อ C และขั้น 5 และในรายงานเสนอช่องทางรอง: สร้างชุดทำมือด้วย `grok_pack.py` ให้ผู้ใช้รันผ่าน Grok Automation extension (ดู vde-videos หัวข้อ "ช่องทางรอง")
4. ถ้า `grok_usd_with_retakes` เกิน `grok_usd_cap` ให้จดไว้ (vde-videos จะหยุดที่เพดาน)
5. บันทึก balance เริ่มต้นของ OpenArt ไว้คำนวณยอดใช้จริงตอนจบ

## ขั้น 3–4 — สาย Scene: ภาพ → ตรวจความต่อเนื่อง → วิดีโอ (v68.2)
แต่ละ Scene เดินสายของตัวเองจนจบวิดีโอโดยไม่รอ Scene อื่น Scene ที่ภาพผ่านก่อนได้ส่งวิดีโอก่อน

**ก่อนแยกสาย (agent หลักทำเอง ตามลำดับ)**
1. ถ้า `image_provider` = `openart`: อัปโหลดภาพตัวละครที่ยังไม่มีใน cache ตาม `vde-images` ข้อ 0.2 (ref_cache.json เป็นไฟล์รวม ห้ามให้หลายตัวเขียน) · `fal` ไม่ต้องทำ
2. `python $S/state.py EPxx budget` แล้วแบ่งเพดานเงินวิดีโอ (`grok_usd_cap` − ที่ใช้ไปแล้ว) ตามสัดส่วนวินาทีที่ต้องสั่งของแต่ละ Scene
3. ตอนสั้น (≤ 12 คลิป หรือ Scene เดียว) → agent หลักทำข้อ A–C เองทีละ Scene ไม่ต้อง spawn

**สั่งสาย Scene** spawn sub-agent (general-purpose) หนึ่งตัวต่อ Scene พร้อมกัน คำสั่งถึงแต่ละตัว:
"ทำสาย Scene SCyy ของ EPxx ตาม `.claude/skills/vde-episode/SKILL.md` หัวข้อ 'ขั้นในสาย Scene' ข้อ A–C เพดานเงินวิดีโอของ Scene นี้ $<n> ห้ามแตะคลิปของ Scene อื่น ห้ามแก้ prompt และห้ามเขียน 06_ผลิต.md รายงานกลับสั้นๆ: ภาพ done/flagged/gave_up พร้อมเหตุผล ปัญหาความต่อเนื่องและวิธีแก้ วิดีโอ done/flagged/gave_up จำนวน take และเงินที่ใช้"
สั่ง "ทำต่อ" → สั่งเฉพาะ Scene ที่ยังมีคลิป todo/retry (ทุกขั้นข้ามคลิปที่เสร็จแล้วเอง)

**ขั้นในสาย Scene** (sub-agent ของ Scene หรือ agent หลักในตอนสั้น)
- **A. ภาพ** — skill `vde-images` เฉพาะ SCyy (ข้ามข้อ 0) จนทุกคลิปเป็น done/flagged/gave_up
- **B. ตรวจความต่อเนื่องข้าม Shot** (ก่อนใช้เงินกับวิดีโอ)
  1. `python $S/continuity_sheet.py EPxx --scene SCyy` → เปิดทุก sheet ด้วย Read คู่กับ `SCyy_image.txt` และ Blocking Table ของ Scene ใน `03_setup_map.md`
  2. ไล่ Shot ติดกันตามลำดับตัดต่อ ตรวจ: ลำดับคนซ้าย→ขวาไม่สลับ (เทียบมุมกล้อง), คนที่ควรอยู่ในส่วนที่เฟรมเห็นไม่หาย, ท่า (ยืน/นั่ง/ระดับน้ำ) สภาพ (เปียก/แห้ง) ชุด และผู้ถือพร็อพต่อกัน (รวมหน้าตาพร็อพชิ้นเดียวกันข้ามช็อต), ฉากหลังเป็นฝั่งที่ถูก
  3. Shot ที่ไม่ผ่าน:
     - แก้ด้วยการกลับภาพซ้ายขวาได้ (ลำดับสลับทั้งเฟรม ไม่มีตัวหนังสือ) → `ffmpeg -i <ภาพ> -vf hflip <ไฟล์ take ถัดไป>` แล้ว `state.py take/select` พร้อม qc "hflip แก้ลำดับ"
     - ต้นเหตุอยู่ใน prompt → **รายงานกลับ agent หลักทันที** แล้วทำคลิปอื่นต่อ agent หลักแก้ prompt ตามโหมดแก้เฉพาะส่วน (AGENTS.md ข้อ 6) → `collect.py` รีเซ็ตคลิปนั้น → ส่งข้อความกลับให้สายเดิมสร้างภาพใหม่และตรวจซ้ำ
     - แก้ไม่ได้ในงบ → `select --flag "<ปัญหาความต่อเนื่อง>"`
- **C. วิดีโอ** — skill `vde-videos` เฉพาะ SCyy ส่งพร้อมกันไม่เกิน `video_parallel` คลิป หยุดที่เพดานเงินของ Scene แล้ว `python $S/continuity_sheet.py EPxx --scene SCyy --kind video` ตรวจซ้ำแบบข้อ B (ไม่ผ่าน → `state.py reset <clip> video` แล้วส่งใหม่ภายในเพดาน หรือ flag)

**รวมผล (agent หลัก)** — รับรายงานทีละสายตามที่เสร็จ จดลงหัวข้อ "ความต่อเนื่อง" ของรายงานขั้น 6 เมื่อทุกสายจบ: `python $S/state.py EPxx status` และ `budget`
- ผู้ใช้สั่ง "ถึงแค่ภาพ" → ทุกสายหยุดหลังข้อ B แล้วข้ามไปขั้น 6
- grok ใช้ไม่ได้ (ขั้น 2 ข้อ 3) → ทุกสายหยุดหลังข้อ B
- สายใดแจ้งเครดิต/ยอดเงินหมด → ส่งข้อความหยุดทุกสายที่ใช้ช่องทางเดียวกัน เขียนรายงานถึงจุดที่ทำได้

## ขั้น 5 — ตัดต่อ
ใช้ skill `vde-edit` (`--burn` เว้นแต่ผู้ใช้ไม่เอาซับ; `--music` เฉพาะเมื่อผู้ใช้ระบุ)

## ขั้น 6 — รายงาน `EPxx/06_ผลิต.md` (agent หลักเขียนเท่านั้น)
```
# EPxx — รายงานผลิต
วันที่: ...
ผล: Clip ใหม่ n | ภาพ done n / flagged n / gave_up n | วิดีโอ done n / flagged n / gave_up n / ข้าม n
ค่าใช้จ่าย: OpenArt ~n เครดิต (balance เริ่ม → จบ) | Grok ~$n (จาก take × วินาที)
ไฟล์ตัดต่อ: EPxx/Edit/EPxx_ตัดต่อ_ซับ.mp4 (ยาว n วิ) | XML: EPxx/Edit/EPxx_timeline.xml

## ความต่อเนื่อง (สาย Scene ข้อ B)
- [Shot — ปัญหาที่พบ — วิธีแก้ (hflip / แก้ prompt / flag)]

## ต้องให้คนตรวจ (เรียงตามความสำคัญ)
- gave_up: [clip — เหตุผล]
- flagged ภาพ: [clip — ปัญหา]
- flagged วิดีโอ: [clip — ปัญหา]
- ต้องฟังลิปซิงก์: [รายการคลิปที่มีบทพูด]
- ตัดต่อ: [warnings จาก edit.py เช่น ทับช่วง จอดำ]
- ปัญหาจาก collect: [...]

## สั่งแก้ต่อ
- สร้างภาพใหม่: "สร้างรูปใหม่ EPxx A005" → state.py reset A005 image แล้วรัน vde-images
- สร้างวิดีโอใหม่: "สร้างวิดีโอใหม่ EPxx A005"
- ตัดต่อใหม่หลังแก้: "ตัดต่อ EPxx"
```
จากนั้นตอบผู้ใช้สั้นๆ: ไฟล์ตัดต่อ ความยาว ค่าใช้จ่าย จำนวนที่ต้องตรวจ และลิงก์ไปที่รายงาน

## จุดหยุด (เท่านั้น)
- ไม่พบตอน / ยังไม่มี prompt
- เครดิต OpenArt ไม่พอสำหรับรอบแรก
- OpenArt หรือ xAI แจ้งเครดิต/ยอดเงินหมดกลางทาง → หยุดขั้นนั้น เขียนรายงานถึงจุดที่ทำได้
ทุกกรณีอื่น (ภาพไม่ผ่าน คลิปล้มเหลว grok ใช้ไม่ได้) ให้บันทึกแล้วทำต่อ

## ระหว่างรอวิดีโอ
ถ้ามีคลิปตอนถัดไปใน `Source/` ที่ยังไม่ได้แกะ และผู้ใช้สั่งทำตอนถัดไปด้วย: spawn sub-agent ทำ `vde-decode` ขั้น 1–5 ของตอนถัดไประหว่างรอสายวิดีโอได้ (ไม่แตะ Bible/ใบสถานะ) แต่ห้ามเริ่มขั้นเขียน prompt ของตอนถัดไปจนกว่าตอนนี้ผ่าน state_keeper

## คำสั่งย่อยที่ผู้ใช้อาจใช้
- "สถานะ EPxx" → `state.py EPxx status` + `budget`
- "สร้างรูปใหม่ EPxx A005" → `state.py EPxx reset A005 image` แล้ว vde-images เฉพาะ Scene ของคลิปนั้น
- "สร้างวิดีโอใหม่ EPxx A005" → `state.py EPxx reset A005 video` แล้ว vde-videos
- "ใช้ภาพ T02 ของ A005" → `state.py EPxx select A005 image --file EPxx/Image/EPxx_A005_T02.png` (วิดีโอจะถูกรีเซ็ตอัตโนมัติ)
