# ผลิตตอน (ตัวสั่งงานหลัก)

อาร์กิวเมนต์: `EPxx` (ชื่อโฟลเดอร์ตอน) และถ้ามี: ชื่อไฟล์เพลง, "ไม่เอาซับ", "ถึงแค่ภาพ"
ทุกคำสั่งรันจากโฟลเดอร์โปรเจกต์ · `S=.claude/skills/vde-episode/scripts` · ค่าตั้ง: `config.json` ในโฟลเดอร์นี้

**โหมดทำงาน:** ทำจนจบโดยไม่ถามระหว่างทาง (ผู้ใช้อาจสั่งแล้วทิ้งไว้ข้ามคืน) หยุดเฉพาะกรณีในหัวข้อ "จุดหยุด" งานนี้รันซ้ำได้ — ทุกขั้นข้ามคลิปที่ทำเสร็จแล้ว

## ขั้น 1 — ตรวจ input และดึง prompt
1. ถ้าไม่มี `EPxx/shots/` หรือ `EPxx/prompts/`: ถ้ามี `input/story/EPxx.txt` ให้แจ้งว่า "ต้องรันขั้นเขียน prompt ใน Codex ตาม AGENTS.md ก่อน" ถ้าไม่มีไฟล์เรื่องด้วย แจ้งว่าไม่พบตอนนี้ → หยุด
2. ใช้ skill `vde-collect` (หรือรัน `python $S/collect.py EPxx` ตรงๆ) จดปัญหาที่ขึ้น `!` ไว้ใส่รายงาน

## ขั้น 2 — ตรวจงบและเครื่องมือ
1. `python $S/state.py EPxx budget`
2. ภาพ: ถ้า `image_provider` = `fal` → `python $S/fal_image.py check` (ไม่พบ key → **หยุด** แนะนำ set-fal-key) ถ้า `openart` → `openart_model_list` ดู `balance` ถ้า balance < `openart_credits_first_pass` → **หยุด** รายงานยอดที่ต้องใช้ ยอดที่มี และ upgradeUrl
3. `grok_list_models` → ถ้า error ให้จดว่า "ขั้นวิดีโอข้าม: grok ใช้ไม่ได้ (<ข้อความ>)" แล้วทำขั้น 3 ต่อ แต่ข้ามขั้น 4–5
4. ถ้า `grok_usd_with_retakes` เกิน `grok_usd_cap` ให้จดไว้ (vde-videos จะหยุดที่เพดาน)
5. บันทึก balance เริ่มต้นของ OpenArt ไว้คำนวณยอดใช้จริงตอนจบ

## ขั้น 3 — ภาพ
1. อัปโหลดภาพตัวละครที่ยังไม่มีใน cache ตาม `vde-images` ข้อ 0.2 (**agent หลักทำเองตามลำดับ ก่อนแยกงาน** เพราะ ref_cache.json เป็นไฟล์รวม)
2. แยกงานต่อ Scene: spawn sub-agent (general-purpose) หนึ่งตัวต่อ Scene ทำขนานกันได้ คำสั่งถึงแต่ละตัว:
   "ใช้ skill vde-images กับ EPxx เฉพาะ SCyy ข้ามข้อ 0 (อัปโหลด ref ทำแล้ว) ทำจนทุกคลิปใน Scene เป็น done/flagged/gave_up แล้วรายงานสั้น: คลิปที่ผ่าน, flagged พร้อมเหตุผล, ล้มเหลว, จำนวน take"
   ถ้าตอนสั้น (≤ 12 คลิป) ทำเองใน agent หลักได้โดยไม่ต้อง spawn
3. รวมผล แล้ว `python $S/state.py EPxx status`
4. ถ้าผู้ใช้สั่ง "ถึงแค่ภาพ" → ทำขั้น 3.5 แล้วข้ามไปขั้น 6

## ขั้น 3.5 — ตรวจความต่อเนื่องข้าม Shot (v68, agent หลักทำเอง ก่อนใช้เงินกับวิดีโอ)
1. `python $S/continuity_sheet.py EPxx` → เปิดทุก sheet ด้วย Read คู่กับไฟล์ `<scene>_image.txt` และ Blocking Table ใน `03_setup_map.md`
2. ไล่ Shot ติดกันตามลำดับตัดต่อ ตรวจ: ลำดับคนซ้าย→ขวาไม่สลับ (เทียบมุมกล้อง), คนที่ควรอยู่ในส่วนที่เฟรมเห็นไม่หาย, ท่า (ยืน/นั่ง/ระดับน้ำ) สภาพ (เปียก/แห้ง) ชุด และผู้ถือพร็อพต่อกัน, ฉากหลังเป็นฝั่งที่ถูก
3. Shot ที่ไม่ผ่าน:
   - แก้ด้วยการกลับภาพซ้ายขวาได้ (ลำดับสลับทั้งเฟรม ไม่มีตัวหนังสือ) → `ffmpeg -i <ภาพ> -vf hflip <ไฟล์ take ถัดไป>` แล้ว `state.py take/select` พร้อม qc "hflip แก้ลำดับ"
   - ต้นเหตุอยู่ใน prompt → แก้ prompt (โหมดแก้เฉพาะส่วน AGENTS.md ข้อ 6) แล้ว `collect.py` จะรีเซ็ตคลิปนั้น สร้างภาพใหม่
   - แก้ไม่ได้ในงบ → `select --flag "<ปัญหาความต่อเนื่อง>"`
4. บันทึกผลตรวจลงรายงานขั้น 6 หัวข้อ "ความต่อเนื่อง"
5. หลังวิดีโอครบ (ก่อนตัดต่อ) รัน `continuity_sheet.py EPxx --kind video` ตรวจซ้ำแบบเดียวกัน

## ขั้น 4 — วิดีโอ
ทำแบบเดียวกับขั้น 3 ด้วย skill `vde-videos` (sub-agent หนึ่งตัวต่อ Scene) แต่ละตัวส่งพร้อมกันไม่เกิน `video_parallel` คลิป
ก่อน spawn ให้ตรวจ budget อีกครั้ง แบ่งเพดานเงินตามสัดส่วนวินาทีของแต่ละ Scene แล้วบอกเพดานในคำสั่งถึง sub-agent

## ขั้น 5 — ตัดต่อ
ใช้ skill `vde-edit` (`--burn` เว้นแต่ผู้ใช้ไม่เอาซับ; `--music` เฉพาะเมื่อผู้ใช้ระบุ)

## ขั้น 6 — รายงาน `EPxx/06_ผลิต.md` (agent หลักเขียนเท่านั้น)
```
# EPxx — รายงานผลิต
วันที่: ...
ผล: Clip ใหม่ n | ภาพ done n / flagged n / gave_up n | วิดีโอ done n / flagged n / gave_up n / ข้าม n
ค่าใช้จ่าย: OpenArt ~n เครดิต (balance เริ่ม → จบ) | Grok ~$n (จาก take × วินาที)
ไฟล์ตัดต่อ: EPxx/Edit/EPxx_ตัดต่อ_ซับ.mp4 (ยาว n วิ) | XML: EPxx/Edit/EPxx_timeline.xml

## ความต่อเนื่อง (ขั้น 3.5)
- [Shot — ปัญหาที่พบ — วิธีแก้ (hflip / แก้ prompt / flag)]

## ต้องให้คนตรวจ (เรียงตามความสำคัญ)
- gave_up: [clip — เหตุผล]
- flagged ภาพ: [clip — ปัญหา]
- flagged วิดีโอ: [clip — ปัญหา]
- ต้องฟังลิปซิงก์: [รายการคลิปที่มีบทพูด]
- ตัดต่อ: [warnings จาก edit.py เช่น ทับช่วง จอดำ]
- ปัญหาจาก collect: [...]

## สั่งแก้ต่อ
- สร้างภาพใหม่: "สร้างรูปใหม่ EPxx A005" → state.py reset A005 image แล้วรัน vde-images
- สร้างวิดีโอใหม่: "สร้างวิดีโอใหม่ EPxx A005"
- ตัดต่อใหม่หลังแก้: "ตัดต่อ EPxx"
```
จากนั้นตอบผู้ใช้สั้นๆ: ไฟล์ตัดต่อ ความยาว ค่าใช้จ่าย จำนวนที่ต้องตรวจ และลิงก์ไปที่รายงาน

## จุดหยุด (เท่านั้น)
- ไม่พบตอน / ยังไม่มี prompt
- เครดิต OpenArt ไม่พอสำหรับรอบแรก
- OpenArt หรือ xAI แจ้งเครดิต/ยอดเงินหมดกลางทาง → หยุดขั้นนั้น เขียนรายงานถึงจุดที่ทำได้
ทุกกรณีอื่น (ภาพไม่ผ่าน คลิปล้มเหลว grok ใช้ไม่ได้) ให้บันทึกแล้วทำต่อ

## คำสั่งย่อยที่ผู้ใช้อาจใช้
- "สถานะ EPxx" → `state.py EPxx status` + `budget`
- "สร้างรูปใหม่ EPxx A005" → `state.py EPxx reset A005 image` แล้ว vde-images เฉพาะ Scene ของคลิปนั้น
- "สร้างวิดีโอใหม่ EPxx A005" → `state.py EPxx reset A005 video` แล้ว vde-videos
- "ใช้ภาพ T02 ของ A005" → `state.py EPxx select A005 image --file EPxx/Image/EPxx_A005_T02.png` (วิดีโอจะถูกรีเซ็ตอัตโนมัติ)
