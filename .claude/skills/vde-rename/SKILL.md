# เปลี่ยนชื่อตัวละคร

ทุกคำสั่งรันจากโฟลเดอร์โปรเจกต์ ตั้ง `PYTHONIOENCODING=utf-8` · `R=.claude/skills/vde-rename/scripts/rename.py`

## ขั้นตอน
1. **รวบรวมคู่ชื่อ** จากคำสั่งผู้ใช้ ถ้าผู้ใช้ให้ "ตั้งชื่อไทยให้" ให้ Claude ตั้งชื่อเอง (สุภาพ เข้ากับฐานะตัวละคร ไม่ซ้ำชื่อที่มีใน `bible/ตัวละคร.md`) และบอกผู้ใช้ว่าตั้งชื่ออะไร
   ใส่ทุกรูปที่ปรากฏในบท เช่น "ประธานคิม", "คุณนายคิม", "คิม" แยกเป็นคู่ของตัวเอง สคริปต์แทนชื่อยาวก่อนชื่อสั้นให้
   ระวังชื่อสั้นที่เป็นส่วนของคำอื่น (เช่น "คิม" ใน "คิมจิ") — ถ้าเสี่ยง ให้ใช้รูปที่ยาวขึ้นแทน
2. **เลือกขอบเขต**
   - `story` (ค่าเริ่มต้น) ไฟล์แกะคลิป `Source/EPxx_แกะคลิป/EPxx.txt` (+ `_บทพูด.txt`) หรือ `input/story/EPxx.txt` — ใช้ก่อนเริ่มขั้นเขียน prompt
   - `episode` + เอกสาร `EPxx/**/*.md` — ใช้เมื่อทำเอกสารตอนแล้ว
   - `all` + `bible/*.md` และ `state/*.md` — ใช้เมื่อชื่อนั้นอยู่ใน Bible แล้ว
3. **นับก่อน** `python $R EPxx "เดิม=ใหม่" ... --scope <ขอบเขต>` ดูจำนวนต่อไฟล์ ถ้าเจอไฟล์ที่ไม่ควรแตะหรือจำนวนผิดคาด ให้ปรับคู่ชื่อ
4. **แทนที่จริง** คำสั่งเดิม + `--apply`
5. **ติดตามผล**
   - บรรทัดบทพูดที่เปลี่ยนชื่อ = บทพูดเปลี่ยนตามคำสั่งผู้ใช้ (ยกเว้นกฎ verbatim) ให้บันทึกในหัวไฟล์เรื่องเป็น `หมายเหตุ n: ผู้ใช้สั่งเปลี่ยนชื่อ <วันที่>: เดิม → ใหม่ ...` และถ้ามี `EPxx/00_สมมติฐาน.md` ให้เพิ่มใต้ "แก้ตามคำสั่ง"
   - ชื่อมาตรฐานของตัวละคร (ชื่อโฟลเดอร์ใน `input/characters/`) **ไม่เปลี่ยน** ถ้าผู้ใช้ไม่ได้สั่ง ชื่อใหม่ให้เพิ่มเป็น "ชื่อเรียกอื่น" ในรายชื่อตัวละคร / Bible
   - ถ้าชื่อเดิมเป็นชื่อมาตรฐานจริง (เช่น ตัวละครใหม่ที่ยังไม่มีโฟลเดอร์ภาพ) ให้เปลี่ยนชื่อโฟลเดอร์ภาพด้วยเฉพาะเมื่อผู้ใช้สั่ง
   - prompt ภาษาอังกฤษไม่ถูกแตะ ถ้า prompt มีชื่อเรียกในบทพูดภาษาไทย ให้ grep `EPxx/prompts/` หาชื่อเดิมแล้วแก้ด้วย Edit
   - ผู้พูดที่ภาพขัดกับชื่อที่ถูกเรียก (เช่น "ประธาน" อาจหมายถึงคนอื่น) ให้ติด `[ตรวจเสียง]` แทนการเดา
6. **รายงาน** คู่ชื่อ จำนวนที่แทนต่อไฟล์ และจุดที่ติด [ตรวจเสียง]
