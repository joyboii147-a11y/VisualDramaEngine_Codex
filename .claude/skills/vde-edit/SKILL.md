# ตัดต่อตอน

อาร์กิวเมนต์: `EPxx` และตัวเลือกจากผู้ใช้ เช่น เพลงประกอบ หรือ "ฝังซับ"

## ขั้นตอน
1. ถ้ายังไม่มี `EPxx/production/plan.json` → `python .claude/skills/vde-episode/scripts/collect.py EPxx`
2. `python .claude/skills/vde-episode/scripts/state.py EPxx status` — ถ้ามีคลิปที่วิดีโอยังไม่ done/flagged ให้แจ้งว่าจะมีจอดำแทน แล้วทำต่อ (ไม่ต้องถาม)
3. รัน:
   ```
   python .claude/skills/vde-edit/scripts/edit.py EPxx --burn [--music "<ไฟล์เพลง>"] [--music-db -22]
   ```
   - ใส่ `--burn` เป็นค่าเริ่มต้น (ได้ทั้งไฟล์ไม่มีซับและไฟล์ฝังซับ) เว้นแต่ผู้ใช้บอกว่าไม่เอาซับ
   - ใส่ `--music` เฉพาะเมื่อผู้ใช้ระบุเพลง ไฟล์เพลงในโฟลเดอร์หลักมี .wav หลายไฟล์ ห้ามเลือกเองถ้าผู้ใช้ไม่ได้บอก
4. ตรวจผล: เปิด 2–3 เฟรมจากไฟล์ฝังซับ (ffmpeg `-ss` แล้ว Read) ว่าซับไทยแสดงและไม่ตกขอบ
5. รายงาน: ไฟล์ผลลัพธ์ (รวม `EPxx_timeline.xml`) ความยาว จำนวนซับ และ **warnings ทุกข้อ** โดยเฉพาะ "ทับช่วง" (ต้องจัดเสียงเอง) และจอดำ

## วิธีตัด (edit.py)
- คลิปใหม่: ข้ามหัว 0.5 วิ เก็บตาม "เวลาใช้จริง" ในไฟล์ Shot; ถ้ามีบทพูดจะขยายจุดตัดไม่ให้กินเสียงพูด (เริ่มก่อนเสียง 0.15 วิ จบหลังเสียง 0.3 วิ)
- REUSE: ใช้คลิปเดิมต่อจากจุดที่ใช้ไปครั้งก่อน
- B-roll ที่ไฟล์ Shot เขียน "ปิดเสียง" → ปิดเสียง
- ซับ `.srt` มาจากบทในเครื่องหมายคำพูดของไฟล์ Shot (คำต่อคำ) ไม่ได้ถอดเสียง — หนึ่งบรรทัดขึ้นครั้งเดียว บนช็อตที่ได้ยินเสียง: B-roll ที่ปิดเสียงหรือคลิปที่เงียบจะยกซับให้ช็อตข้างเคียงที่มีบทเดียวกันและไม่ปิดเสียง ถ้าไม่มีก็คงซับไว้ที่เดิม และไม่ซ้ำกับซับก่อนหน้า
- `--skip "S098,S103-S111"` ตัด Shot ออกจากงานตัดต่อโดยไม่แก้ไฟล์ Shot (เช่น ช็อตที่ไม่มีวิดีโอ หรือช่วงทวนที่ไม่อยู่ในไฟล์เรื่อง) — บันทึกเหตุผลในรายงาน
- ตรวจซับกับไฟล์เรื่อง: บทในไฟล์ `input/story/EPxx.txt` เรียงต่อกันต้องเท่ากับข้อความใน `.srt` เรียงต่อกัน
- ปรับเสียงรวมเป็น -14 LUFS (มาตรฐานโซเชียล) ผลลัพธ์ 720×1280 24fps

## ผลลัพธ์ใน `EPxx/Edit/`
`EPxx_ตัดต่อ.mp4` · `EPxx_ตัดต่อ_ซับ.mp4` · `EPxx.srt` (นำเข้า CapCut/Premiere ได้) · `EPxx_edl.csv` (จุดเข้าออกทุก Shot)
· `EPxx_timeline.xml` ไทม์ไลน์สำหรับ Premiere Pro / DaVinci Resolve — edit.py เรียก skill `vde-xml` ให้อัตโนมัติตอนจบ (ถ้าล้มเหลวจะขึ้นใน warnings)
