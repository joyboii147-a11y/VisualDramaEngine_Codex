## SC01 — ห้องนอนโรงแรม L02 / INT. / กลางวัน

### Scene Geography
- สถานที่: L02 (ภาคเพิ่มเติม EP29 ใน bible/สถานที่.md) — [เสนอ] ห้องเดียวกับ EP27
- จุดคงที่: ผนัง A = หัวเตียงบุนวมครีม + โต๊ะข้างเตียง + โคมไฟตั้งพื้น (ซ้ายของหัวเตียง); เตียงคู่ผ้าปูขาว ผ้าคลุมปลายเตียงเหลืองทอง; ผนัง B (ขวา) = หน้าต่างม่านโปร่ง และทางออกห้องนอกกรอบฝั่ง B; ผนัง C (หลังมุมอ้างอิง) = ผนังไม้อ่อน + ทีวีจอดำ + ตู้เตี้ยใต้ทีวี
- กลุ่ม [ผู้ใช้]: วิทย์และไอรินนั่งขอบเตียงปลายเตียงติดกัน วิทย์ซ้าย ไอรินขวา หันหน้าเข้าหาผนัง C
- สถานะเริ่มฉาก: วิทย์ C05-W09 แห้ง ถือ P14 มือขวาแนบหูขวา; ไอริน C04-W18 แห้ง มือประสานบนตัก ผมยาวปล่อย ไม่มีรอยน้ำตา/แผล; P08 และ P07 ไม่อยู่ในฉาก
- แสง: soft frontal key จากซ้ายกล้อง (ไฟหลืบเพดาน) + แสงหน้าต่างฝั่ง B เป็น fill ขวากล้อง + โคมตั้งพื้นอุ่นหลังซ้าย (Lighting State L02 EP29)

**มุมอ้างอิง SC01: ยืนหน้าทีวี (ผนัง C) หันเข้าหาปลายเตียงและหัวเตียง (ผนัง A)**

## SC02 — โถงทางเดิน L03 / INT. / กลางคืน

### Scene Geography
- สถานที่: L03 (ใหม่) — ทางเดินยาวแนวซ้าย–ขวา ปลายซ้าย E1 แผงระแนงไม้ไฟฟ้าเย็น; ผนังฝั่ง B หินเรียงสีเทาอุ่นมีไฟประดับ มุมนั่งโซฟา/อาร์มแชร์เบจช่วงขวา; ผนังฝั่ง A ระแนงไม้ (หลังมุมอ้างอิง)
- [ผู้ใช้] เลขาเจตเดินมาตามทางเดิน ริต้าเดินเข้ามาขวางหน้า; ไม่มีใครอื่นในฉาก
- [ผังออกแบบ] เลขาเจตเดินจากปลายซ้าย (E1) ไปทางขวา; ริต้ามาจากด้านขวา (ทางมุมโซฟา) หยุดขวางหน้า ทั้งสองยืนหันหน้าเข้าหากันตามแนวทางเดิน ห่าง ~0.8 ม. กลางทางเดิน
- สถานะเริ่มฉาก: เลขาเจต C13-W01 ถือ P13 มือขวา; ริต้า C06-W07 กระเป๋าสายโซ่ไหล่ซ้าย ถือ P12 มือขวา (เริ่มเห็นชัดตอนชูใน S017) [เสนอ: ก่อนชู ถือแนบลำตัวระดับเอว]; ทั้งคู่แห้ง ไม่มีบาดแผล

**มุมอ้างอิง SC02: ยืนชิดผนังระแนงฝั่ง A กลางทางเดิน มองข้ามไปผนังหินฝั่ง B (ปลายระแนงฟ้า E1 อยู่ซ้าย มุมโซฟาอยู่ขวา)**

## SC03 — โถงงานเลี้ยงผนังกระจก L04 / INT. / กลางคืน

### Scene Geography
- สถานที่: L04 (ใหม่) — โต๊ะยืนกลมผ้าขาวมีแจกันดอกไม้กลางโถง; ผนังกระจกโครงเหล็กดำ + ประตูกระจกด้านหลังกลุ่ม; ผนังขาวม่านโปร่งด้านซ้าย; ช่องทางเข้าจากโถงทางเดินด้านขวา [ผังออกแบบ]
- [ผู้ใช้] ริต้ายืนฝั่งซ้ายของโต๊ะตั้งแต่ต้น; เลขาเจตเดินเข้ามาที่โต๊ะ; วิทย์+ไอรินเดินเข้ามาสมทบ; แม่วิทย์เดินตามมา; พ่อวิทย์และการ์ดเข้ามาทีหลัง; ลำดับ S047: ริต้า · เลขาเจต · วิทย์ · ไอริน · แม่วิทย์ (ไอรินไม่ได้อยู่ในรายการ S047 ของไฟล์เรื่อง แต่ Presence Ledger ให้อยู่ระหว่างวิทย์กับแม่ และเฟรมยืนยัน)
- [ผังออกแบบ] กลุ่มยืนเป็นแนวโค้งฝั่งไกลของโต๊ะ (ระหว่างโต๊ะกับผนังกระจก) หันหน้าเข้าโต๊ะ/กล้องอ้างอิง; ทุกคนที่เข้าฉากเดินมาจากช่องทางเข้าขวา
- [เสนอ] พ่อวิทย์หยุดที่มุมขวาของโต๊ะ ถัดขวาของแม่วิทย์ เยื้องมาทางกล้องเล็กน้อย (ให้ S056 แม่ซ้าย พ่อขวา ได้ตามไฟล์เรื่อง); การ์ด 1 ยืนหลังพ่อค่อนไปทางกระจก, การ์ด 2 ยืนหลังพ่อค่อนมาทางกล้อง — ทั้งคู่ขวาสุดใกล้ช่องทางเข้า
- [แก้โดย agent หลัก] S050 วิทย์มอง**ซ้ายเฟรม**หาพ่อวิทย์ ตามไฟล์เรื่องและภาพนิ่งคลิปต้นฉบับ 01:38.5–01:39.5 (ตรวจแล้ว) ไม่ข้ามเส้น 180° กับ S049/S051 ที่พ่อวิทย์มองขวาเฟรมจากฝั่งกระจก
- สถานะเริ่มฉาก: ทุกคนแห้ง ไม่มีบาดแผล; ริต้า C06-W07 กระเป๋าไหล่ซ้าย มือว่าง (P12 ไม่อยู่ในมือ [เสนอ]); เลขาเจต C13-W01 ถือ P13 มือขวา; วิทย์ C05-W10 ไม่มี P14 ในมือ [เสนอ]; ไอริน C04-W18 มือว่าง; แม่วิทย์ C01-W08 มือว่าง; พ่อวิทย์ C12-W01 มือว่าง; การ์ด C14/C15-W01 มือว่างประสานหน้า

**มุมอ้างอิง SC03: ยืนฝั่งในโถงหน้าโต๊ะกลม มองข้ามโต๊ะไปผนังกระจก (ม่านขาวซ้าย ช่องทางเข้าขวา)**
