# EP25-26 — Scene Geography + Setup Map

## Scene Geography

### SC01 — โซน A งานจัดแสดงอัญมณีริมสระ
- สถานะเริ่มฉาก: แม่วิทย์ (C01-W01) อยู่กลางกลุ่มสนทนาใกล้ทางเดินรับแขก ไม่มีของในมือ ร่างกายปกติ; แขกหญิง 1 (C02-W01) และแขกหญิง 2 (C03-W01) ยืนเป็นครึ่งวงหันหาแม่วิทย์ ไม่มีของในมือ; ไอริน (C04-W01) และวิทย์ (C05-W01) เดินเข้าจากทางเดินโซน B ไม่มีของในมือ ร่างกายปกติ; ริต้า (C06-W01) เข้าจากขอบวงด้านโซน C ไม่มีของในมือ ร่างกายปกติ.
- การเคลื่อนที่: ไอรินยึดด้านซ้ายของวิทย์เมื่อเข้าวง; ริต้าแทรกเข้าหาแม่วิทย์จากฝั่งสระ; หลัง D014 วิทย์พาไอรินเดินจากโซน A ไปโซน B และไอรินหันกลับยิ้มเยาะริต้า. แกนสนทนาแม่วิทย์–ริต้าอยู่ตามแนว A↔C; วิทย์ก้าวเข้าบนแนวเดียวกันเพื่อขวาง.

### SC02 — โซน B โต๊ะโชว์อัญมณี
- สถานะเริ่มฉาก: แม่วิทย์ (C01-W01) อยู่ฝั่ง A ของ P01 หันเข้าตู้; ไอริน (C04-W01) ยืนข้างวิทย์ฝั่ง A ของตู้ ไม่มีของในมือ ร่างกายปกติ; วิทย์ (C05-W01) อยู่ข้างไอรินและหยิบ P05 ด้วยมือขวาเฉพาะก่อน D029 [เสนอ]; ริต้า (C06-W01) อยู่ด้าน C ของตู้ มองกลุ่ม ไม่มีของในมือ ร่างกายปกติ; พนักงานหญิง (C07-W01) เริ่มนอกกรอบทางโซน D.
- การเคลื่อนที่: ทุกคนยืนรอบ P01 โดยไม่ข้ามตู้; ริต้าเข้าหาขอบตู้ใน D027 แต่ไม่ยึดพร็อพ. หลัง D029 พนักงานหญิงเข้าจาก D แจ้งวิทย์; D031 วิทย์เดินออกทาง D เพื่อรับแขก. ไอรินและแม่วิทย์ยังอยู่ฝั่ง A ของตู้ แล้วเปลี่ยนไปยืนขอบสระใน SC03 โดยเดินผ่านทางเปิด A→C [เสนอเพื่อเชื่อมต่อเนื่อง].

### SC03 — โซน C ขอบสระ
- สถานะเริ่มฉาก: แม่วิทย์ (C01-W01) และไอริน (C04-W01) ยืนคู่กันบนพื้นหินห่างขอบสระอย่างน้อยหนึ่งก้าว หันเข้าหากัน ไม่มีของในมือ ร่างกายแห้ง; ริต้า (C06-W01) เข้ามาจากโซน B ถือ P06 ในมือขวา [เสนอ] ร่างกายแห้ง; แขกหญิง 1 (C02-W01), แขกหญิง 2 (C03-W01), พนักงานหญิง (C07-W01) อยู่ลึกไปทาง A/B; วิทย์ (C05-W01) อยู่นอกพื้นที่ทางโซน D หลังจากปลีกตัว; ชายชุดดำ (C08-W01) ยังนอกกรอบ.
- การเคลื่อนที่และความต่อเนื่อง: ริต้าเดินเข้าหาแม่วิทย์แต่ส้นสูงสะดุด เซถอยหลังลงน้ำเอง; แม่วิทย์ยังอยู่ขอบสระและหันตามริต้าด้วยความตกใจ จึงเปิดช่องให้ชายชุดดำเข้าจากด้านหลังฝั่ง A ผลักเธอลงน้ำ. วิทย์กลับเข้ามาจาก D หลังได้ยิน/เห็นเหตุ ไม่ใช่ปรากฏอยู่ข้างแม่วิทย์ก่อนเกิดเหตุ. แม่วิทย์และริต้าลอยคอแยกกันในน้ำ; ไอรินกระโดดจากขอบใกล้แม่วิทย์ลงช่วยพยุงไปยังขอบสระ. หลังไอรินลงน้ำ ผมและชุด C04-W01 เปียก; แม่วิทย์ชุด C01-W01 และผมเปียก; ริต้า C06-W01 และผมเปียก. ชายชุดดำถอยออกนอกกรอบหลังผลัก [เสนอ].
