## ตรวจก่อนผลิต
- ต้องแก้เอกสารค้าง 0 / ควรแก้ค้าง 0 — ผลรอบแรกตรวจครบ 180 prompt รอบสองตรวจเฉพาะจุดแก้ ดู `04_review.md`
- ต้องให้ผู้ใช้ตัดสินหลังฟังเสียง: D010 “เรื่องลูกสาวคุณ” และ D015 “สัญญามั่น” คง verbatim; รวมจุดตรวจเสียง S001/S004/S007/S017/S034–035/S045/S087 และการแบ่งคำตามหมายเหตุต้นทาง ห้ามแก้คำเอง
- ส่วนล่างพ่อวิทย์/ริต้าและรองเท้าศิลาที่ภาพชุดไม่ครอบคลุมเป็นข้อเสนอ; การ crop คนขอบภาพที่ไม่ทราบเจ้าของ จำนวนแขก/การ์ด และภาพแรก S047 อยู่ใน `00_สมมติฐาน.md`
- ช็อตกว้างหลายคนแนบ OpenArt ได้ 2 รูปตามแผน คนไม่มีภาพและคนไม่ได้แนบใช้คำบรรยาย ต้องตรวจใบหน้า ชุด จำนวนคนและผังจากภาพจริง
- ตรวจมือขวาวิทย์–มือซ้ายไอริน โทรศัพท์หูขวาริต้า การดึงชายเสื้อ และกล้องแพน/tilt จากผลจริงก่อนใช้วิดีโอ
- ทุกคลิปมีภาพตั้งต้นของตัวเอง ไม่ใช้เฟรมท้ายคลิปก่อน; B-roll เงียบใช้เสียงจาก A-roll ตาม Shot ไม่ผลิตประโยคซ้ำ

## ลำดับผลิตที่แนะนำ
1. ตรวจรายการคำกำกวม/จุดตัดเสียงและข้อเสนอภาพในไฟล์สมมติฐานก่อนเริ่มผลิตเสียง
2. สร้างภาพยึดของตัวละครใหม่/ตัวประกอบที่ต้องเห็นหน้าก่อนหากต้องการอัตลักษณ์ข้ามคลิป แล้วอัปเดต prompt เฉพาะที่ได้รับผล
3. สร้างภาพทุกคลิปจาก prompt และภาพแนบตาม Shot; เลือก 9:16 ที่หน้า OpenArt ตรวจชุด จำนวนคน ตำแหน่ง มือ และขนาดภาพก่อนส่งต่อ
4. สร้างวิดีโอจากภาพที่เลือกของคลิปเดียวกัน ข้อความใต้เส้นคั่นพร้อมใช้แยกเดี่ยว; ตรวจความยาวที่หน้า Grok คลิปเกิน 6 วิระบุเหตุผลไว้ใน Shot ไม่เร่งคำให้จบเร็ว
5. ตัดต่อตามลำดับ Shot ใช้ REUSE S035→A102 และ S058→A111 ตาม marker ไม่เริ่มเสียง/การกระทำซ้ำ; S046 จอดำ 0.5 วิทำในงานตัดต่อ; B015→A015เป็นการตัดกว้างขึ้นโดยตั้งใจหลังหยุดเดิน
6. ตรวจเสียง ลิปซิงก์ หน้าตา ผัง มือ และรอยต่อจากผลผลิตจริงก่อนส่งงาน
