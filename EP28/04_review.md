## ความเสี่ยงที่ต้องตรวจจากผลผลิตจริง
- ฉากกว้าง A007 มีคน 5 คน, A015/B015 มี 8 คน, B127/A124 มี 10 คน แต่แนบ OpenArt ได้ตามแผน 2 ภาพ อัตลักษณ์คนอื่นใช้คำบรรยาย ต้องตรวจคน/หน้า/ชุดไม่สลับ
- ตัวประกอบไม่มีภาพอ้างอิง; ส่วนล่างบางชุดเป็นข้อเสนอจาก Bible ไม่ใช่ภาพยืนยัน
- มือขวาวิทย์–มือซ้ายไอริน การส่งต่อท่าและการจับชายเสื้อต้องเทียบภาพจริง
- D010 “เรื่องลูกสาวคุณ”, D015 “สัญญามั่น” และจุดตัดเสียงที่ input ติดป้ายตรวจเสียง คง verbatim ไม่แก้เอง
- เวลาใช้จริงและเวลาสั่งสร้างเป็นประมาณการ ไม่รับรองความยาวการพูด/ลิปซิงก์จริง

## การตรวจไฟล์โดย agent หลัก
- 93 แถว Shot (ภาพใช้ใหม่/REUSE 92 + EDIT จอดำ 1)
- 90 คลิปใหม่ / 180 prompt / 90 คู่ ไม่มีไฟล์ขาดหรือ orphan
- บล็อกภาษาอังกฤษใต้เส้นคั่นมีภาษาไทยเฉพาะบทใน EXACT THAI DIALOGUE
- ภาพแนบมีจริงและไม่เกิน 2 ต่อ image prompt; input ไม่ถูกแก้
