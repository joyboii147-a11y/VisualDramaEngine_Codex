## SC01 — ห้องตรวจ L05 / INT. / กลางวัน

### Scene Geography
- สถานที่: L05 ห้องตรวจแพทย์ (bible/สถานที่.md) — ห้องเดียวกับ SC03 และ SC06 โซน B [เสนอ จากภาพ S009 ที่เห็นท็อปกระจกดำ]
- จุดคงที่: ผนัง A = ฝั่งหมอ (ผนังขาวนวล ชั้นไม้เลื้อย เก้าอี้หนังดำพนักสูง); โต๊ะท็อปกระจกดำกลางห้องขนานผนัง A — ปลายด้าน D มีจอคอมพิวเตอร์ภาพอัลตราซาวด์และคีย์บอร์ด กระถางต้นไม้อวบน้ำสีครีมบนโต๊ะฝั่ง C ค่อนไปทางปลาย D (ใกล้มุมอ้างอิง ตามภาพ S003/S025) แฟ้มเปิดมีภาพพิมพ์อัลตราซาวด์กลางโต๊ะ; ฝั่ง C = ฝั่งคนไข้; ผนัง B = โปสเตอร์ ต้นไทร โคมตั้งพื้น ชั้นแฟ้ม (ช่วงใกล้ C) + หน้าต่างม่านม้วน (ช่วงใกล้ A); ผนัง D = เทาอ่อนเรียบ (ประตู: ยังไม่ทราบ)
- กลุ่ม [ผู้ใช้]: หมอนั่งที่โต๊ะทำงาน ไอรินและมีอานั่งฝั่งตรงข้าม (ฝั่ง C)
- [เสนอ จากภาพ S001/S002/S003/S004/S025] มีอานั่งเก้าอี้คนไข้ตัวที่ 1 กลางฝั่ง C ตรงข้ามหมอ; ไอรินนั่งเก้าอี้คนไข้ตัวที่ 2 ที่มุมโต๊ะฝั่ง C ปลายด้าน B หมุนเก้าอี้เฉียงเข้าหาฝั่ง D/มีอา — ทั้งคู่ยังอยู่ "ฝั่งตรงข้ามหมอ" ตามไฟล์เรื่อง
- สถานะเริ่มฉาก: หมอ C17-W01 แห้ง มือประสานบนโต๊ะ; มีอา C16-W01 แห้ง มือวางบนตัก; ไอริน C04-W19 แห้ง ไม่มีแว่น ไม่สะพายเป้ (เป้วางพื้นข้างเก้าอี้นอกเฟรม) ท้องแบน; P16 นามบัตร: ไอรินถือมือขวาวางบนตัก/ขอบโต๊ะ ไม่เห็นจนถึง B05 [เสนอ]; P15 โทรศัพท์ไอริน: ในกระเป๋าฮู้ด ไม่เห็น [เสนอ]
- แสง: Lighting State L05 — แสงหน้าต่างม่านม้วนจากผนัง B ช่วงใกล้ A + ไฟเพดานขาวนวล

**มุมอ้างอิง SC01 (ใช้ทั้ง SC01, SC03, SC06 โซน B): ยืนที่ผนัง D (ปลายโต๊ะด้านจอคอมพิวเตอร์) มองตามความยาวโต๊ะไปทางผนัง B — ซ้าย = ฝั่ง C (คนไข้), ขวา = ผนัง A (หมอ)**

## SC02 — ห้องอาหารบ้านวิทย์ L06 / INT. / กลางวัน

### Scene Geography
- สถานที่: L06 ห้องอาหารบ้านวิทย์
- จุดคงที่: โต๊ะยาวท็อปหินอ่อนขาวขาโครงทอง แกนยาวขนานผนังตู้โชว์; ผนังไกล = ตู้โชว์กระจกบานสูง (ซ้าย-กลาง) + ชั้นไม้น้ำตาลแดงเข้มมีประติมากรรมทอง (กลาง-ขวา); ผนังซ้าย = ผนังเทาขาวเรียบมีสวิตช์; ผนังขวา = หน้าต่างบานใหญ่; เพดาน = ฝ้าไฟทอง โคมระย้าคริสตัลเหนือโต๊ะ; ผนังใกล้ = ยังไม่ทราบ [เสนอ: แจกันดอกเหลืองนวลบนตู้เตี้ย]
- กลุ่ม [ผู้ใช้ "วิทย์นั่งหัวโต๊ะ พ่อแม่นั่งด้านข้าง"] → **[ผู้ใช้สั่งยึดภาพ S010/S013 ไม่ใช่ "หัวโต๊ะ"]** อ่านจากภาพ: วิทย์นั่งด้านสั้นปลายซ้ายของโต๊ะ (S010 เห็นด้านข้างหันขวา เก้าอี้อยู่หลังตัวทางซ้าย; S013 มองจากหลังวิทย์เห็นพ่ออยู่ฝั่งไกลและแม่อยู่ปลายโต๊ะไกล) — **ไม่เรียกว่าหัวโต๊ะ** และไม่ระบุว่าด้านไหนเป็นหัว; พ่อวิทย์นั่งด้านยาวฝั่งไกล (หลังพิงผนังตู้โชว์) ค่อนไปทางปลายขวา หันหน้าเข้าหาฝั่งใกล้/เหลียวซ้ายหาวิทย์; แม่วิทย์นั่งด้านสั้นปลายขวา (หลังหันไปทางหน้าต่าง) หันซ้ายเข้าหาวิทย์ตามความยาวโต๊ะ
- สถานะเริ่มฉาก: วิทย์ C05-W11 (สวมแจ็กเก็ตสูทดำ) แห้ง ถือตะเกียบมือขวา; พ่อ C12-W02 แห้ง ถือช้อนมือขวา; แม่ C01-W01 แห้ง ถือตะเกียบมือขวา; P14 วางบนโต๊ะทางขวาของชามข้าววิทย์ หน้าจอขึ้น [เสนอ]; บนโต๊ะ: ชามข้าวลายน้ำเงินขาว จานกับข้าว แก้วน้ำใส
- แสง: Lighting State L06 — แสงหน้าต่างผนังขวา + ไฟฝ้าทองและโคมระย้าอุ่น

**มุมอ้างอิง SC02/SC04: ยืนฝั่งใกล้ของโต๊ะ (ด้านยาวที่ว่าง) มองข้ามโต๊ะไปผนังตู้โชว์ (= มุมภาพ S010) — ซ้าย = ผนังเทาขาว/ปลายโต๊ะวิทย์, ขวา = ผนังหน้าต่าง/ปลายโต๊ะแม่**
